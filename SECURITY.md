# Security policy

## Supported versions

Only the [latest release](https://github.com/AnnasMustafaDev/talkflow-releases/releases/latest) gets security fixes.

## Reporting a vulnerability

Please **don't** open a public issue for a security problem. Report it privately through [GitHub's private vulnerability reporting](https://github.com/AnnasMustafaDev/talkflow-releases/security/advisories/new) for this repository. Include the Talkflow version, your Windows version, and steps to reproduce.

You'll get a reply within 7 days. A fix ships in a new release, and the advisory is published once it's out.

Never include your API keys in a report.
